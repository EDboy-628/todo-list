# 智能待办清单（AI 生活清单）

一个纯前端、无需后端的「带 AI 智能拆解感的待办清单」。输入一句话，本地规则引擎把它自动拆成**多个场景分组** + **带优先级和截止日期**的子任务。

## 功能

### AI 智能拆解
- **多场景合并**：一句话命中多个场景时全部输出。如「出差顺便去旅行」→ 出差准备 + 旅行计划两组任务
- **自然语言时间**：输入「下周三交报告」「明天去医院体检」，自动识别截止日期
- **预览确认**：AI 结果先以卡片预览，可勾选/修改，确认后才写入
- **常用模板**：预置出差/学习/购物/聚会/搬家/健身模板，一键拆解；支持保存新模板

### 清单管理
- **分组视图**：按场景分组（✈️出差/🧳旅行/📚学习/🛒购物/🏃健康/📦搬家/🎂聚会/💼求职…15+ 场景），组头带进度条，支持折叠
- **优先级**：高/中/低三档，按钮循环切换，可筛选「高优先级」
- **截止日期**：超时自动标记「⚠ 已逾期 / 📅 今天截止 / 还有X天」
- **子任务嵌套**：任务可展开下级子任务，子任务全完成父任务自动完成
- **批量操作**：Esc 进入批量模式，多选后批量完成/高优/删除
- **周期重复**：任务可设为「每周重复」，完成后自动生成下周副本
- **拖拽排序** + **双击内联编辑** + **搜索过滤** + **撤销删除**
- **统计面板**：📈 完成率、按分组分布、按优先级分布

### 数据处理
- **持久化**：localStorage 存储，刷新不丢
- **导出/导入**：一键备份为 JSON，快速恢复
- **到期提醒**：有逾期任务时顶部横幅提示
- **深/浅主题**：🌙 切换，记住偏好

### 趣味反馈
- 完成任务播放**上扬音效** + **Confetti 彩带**粒子特效

## 技术栈

纯前端三件套，无构建、无依赖，双击 `index.html` 即可运行：
- `index.html` — 页面结构
- `style.css` — 样式（含深浅主题变量）
- `script.js` — 逻辑（本地规则解析引擎 + 交互）

## 快捷操作

| 按键 | 作用 |
|------|------|
| `Enter` | 触发 AI 拆解 |
| `Ctrl/Cmd + K` | 聚焦输入框 |
| `Esc` | 关闭弹窗 / 退出批量模式 |
| 双击任务文本 | 内联编辑 |
| 拖拽任务 | 排序 |

## 用法示例

1. 双击 `index.html` 在浏览器打开。
2. 输入一句话，如：
   - `下周三去上海出差三天` → 出差分组 + 自动设置下周三截止
   - `周末去超市买菜，顺便健身` → 购物 + 健康运动两组任务
   - `下周搬家并开个party` → 搬家 + 聚会安排
3. 在预览卡片勾选/取消 → 点「确认添加」。
4. 勾选圆圈完成 / 双击改文本 / 按 `+` 加子任务 / 按 `Esc` 批量操作。

## 本地规则解析（伪 AI）

`script.js` 中的 `RULES` 数组按关键词匹配**15+ 个场景**，`parseInput()` 负责多场景合并，`extractNaturalTime()` 负责自然语言时间提取。未来接真实 AI 时，只需替换这两个函数，UI 无需改动。
