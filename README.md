# 智能待办清单（AI 生活清单）

> 输入一句话，本地规则引擎自动把它拆成 **多个场景分组** + **带优先级与截止日期** 的任务清单。
> 纯前端、零依赖、零构建，双击 `index.html` 就能用。

## 功能一览

### 🪄 AI 智能拆解（本地规则引擎）

- **多场景合并**：一句话命中多个场景时全部输出。如「出差顺便去旅行」→ 出差准备 + 旅行计划 两组任务
- **自然语言时间**：输入「下周三交报告」「明天去医院体检」，自动识别并写入截止日期
- **预览确认**：候选任务先以卡片预览，可逐条勾选 / 取消，点「确认添加」才写入清单
- **常用模板**：内置出差 / 学习 / 购物 / 聚会 / 搬家 / 健身 6 个模板，一键填入；也可把任意句子保存为新模板

### 📋 清单管理

- **分组视图**：按场景分组，组头显示图标、`已完成/总数 · 百分比` 与进度条，点击组头可折叠 / 展开
- **优先级**：高 / 中 / 低三档，任务右侧 `⤴` 循环切换，顶部可单独筛选「高优先级」
- **截止日期**：自动标记 `⚠ 已逾期` / `📅 今天截止` / `📅 还有 X 天`（3 天内）
- **子任务嵌套**：任务可展开下级子任务（`▶ 2/5` 计数），子任务全部完成时父任务自动完成
- **周期重复**：任务可设为「🔄 每周重复」，完成后自动生成下一周（+7 天）的未完成副本
- **排序与编辑**：拖拽排序（`⋮⋮` 手柄）、双击任务文本内联编辑、搜索框按「任务内容 / 分组名」过滤
- **撤销删除**：删除后底部出现撤销条，6 秒内可一键恢复
- **批量操作**：顶栏 `☑️` 进入批量模式，点选任务即可批量完成 / 设为高优 / 删除，`Esc` 或批量栏「退出」结束
- **数据统计**：`📈` 面板展示总任务 / 已完成 / 未完成、整体完成率、按分组分布、按优先级分布

### 💾 数据与备份

- **持久化**：全部数据存于 `localStorage`，刷新、关机都不丢
- **导出 / 导入**：一键导出 `todo-backup-YYYY-MM-DD.json`（含任务与模板），导入即可恢复
- **到期提醒**：存在逾期任务时顶部横幅提示（可关闭）；开启顶栏 `🔔` 通知后，每天首次检测到逾期会推送一条系统通知
- **深浅主题**：`🌙 / ☀️` 一键切换并记住偏好

### 🎉 趣味反馈

- 完成任务播放 **C 大调上行三音音效**（Web Audio 实时合成，无需音频文件）+ **Confetti 彩带粒子**特效（Canvas，120 粒）
- 轻量 Toast 操作提示、拆解时「三点」思考动画（约 0.8 秒）

## 快速开始

1. 克隆或下载本仓库：

   ```bash
   git clone https://github.com/EDboy-628/todo-list.git
   ```

2. 用浏览器打开 `index.html`（双击即可）—— 无需 `npm install`、无需构建、无需后端。
3. 首次打开会自带 8 条演示任务（出差准备 / 学习计划 / 购物采购）并立即写入 `localStorage`；可逐条删除，或清除 `smartTodo.v2` 键后刷新，即会重新生成演示数据。

## 使用指南

1. 在输入框写一句话（空状态里的示例标签可一键填入）：
   - `下周三去上海出差三天` → ✈️ 出差准备分组，截止日期自动识别为下周三
   - `周末去超市买菜，顺便健身` → 🛒 购物采购 + 🏃 健康运动 两组任务
   - `下周搬家并开个party` → 📦 搬家事项 + 🎂 聚会安排 两组任务
2. 等待约 0.8 秒的「AI 正在理解你的需求…」动画，预览卡片会列出全部候选任务；取消勾选不需要的条目，点 **确认添加**。
3. 回到清单后：点圆圈完成 / 双击文本改文字 / `+` 加子任务 / `🔄` 开每周重复 / `⋮⋮` 拖动排序。
4. 用筛选栏与搜索框快速定位任务；误删了点底部的「撤销」。
5. 需要一次处理多条时，点顶栏 `☑️` 进入批量模式：任务行出现勾选框，点选后批量完成 / 高优 / 删除，`Esc` 或批量栏「退出」结束。
6. 希望任务逾期时收到系统提醒，点顶栏 `🔔` 授权开启（需 `https` / `localhost` 环境）。

## 拆解引擎是怎么工作的

`script.js` 内置一套**本地规则引擎**（不联网、不上传任何数据），整体流程：

```
输入文本 ─► parseInput()          ─► 命中 0..N 个场景分组（同分组去重）
        └─► extractNaturalTime() ─► 识别到明确时间词则覆盖分组默认截止日期
                                   └─► 预览卡片（勾选）─► 确认写入 todos
```

### 1. 场景规则（`RULES`：14 条规则 + 1 个兜底分组）

| 分组 | 触发关键词（正则） | 默认截止 |
|------|-------------------|----------|
| ✈️ 出差准备 | 出差 | +1 天 |
| ✈️ 旅行计划（组图标 🧳） | 旅行 / 旅游 / 去玩 / 度假 / 出游 | +2 天 |
| 📚 学习计划 | 学习 / 看书 / 读书 / 复习 / 考试 / 备考 / 背 | +3 天 |
| 🛒 购物采购 | 购物 / 采购 / 买 / 超市 / 买菜 | +1 天 |
| 🏃 健康运动 | 健身 / 跑步 / 运动 / 锻炼 / 减肥 / 瑜伽 | +1 天 |
| 📦 搬家事项 | 搬家 / 搬迁 | +5 天 |
| 🎂 聚会安排 | 聚会 / 聚餐 / 派对 / 请客 / 生日 / 庆祝 | +3 天 |
| 💼 求职面试 | 面试 / 求职 / 找工作 / 应聘 | +2 天 |
| 🏥 就医体检 | 看病 / 去医院 / 就医 / 体检 / 挂号 | +1 天 |
| 🍳 下厨烹饪 | 做饭 / 下厨 / 烹饪 / 做菜 | +1 天 |
| 👶 育儿日常 | 育儿 / 带娃 / 孩子 / 宝宝 | +1 天 |
| 💼 工作任务 | 工作 / 汇报 / 开会 / 方案 / 项目 / 周报 / 月报 | +1 天 |
| 🧹 整理打扫 | 整理 / 打扫 / 清洁 / 大扫除 / 收拾 | +1 天 |

| 📌 待办事项 | 以上均未命中时的兜底（通用「拆解四步」任务） | +1 天 |

> 命中多条规则时**全部保留**（同一分组只输出一次），每条任务带规则中预设的优先级。

### 2. 自然语言时间（`extractNaturalTime`）

- 支持的时间词：`今天` `今晚` `明早` `明天` `明天白天` `后天` `大后天` `这周` `本周`、`(下|这|本)周X`、`下个月X号`
- 识别顺序：先匹配「周X」，再匹配相对天词，最后匹配「下个月X号」
- 只写「周三」（不带 下 / 这 / 本）时，按**最近的周三**计算（可以是今天，最多 6 天后）；「下周三」则严格跳到下一周
- 命中时间词后，本次拆解产生的**所有任务**统一使用该日期；没命中（如只写了「周末」）则回退到分组默认天数
- 小细节：预览气泡中的时间文案固定显示为「下周X」，以任务卡上的实际日期为准

### 3. 想接真实大模型？

只需替换 `parseInput()` 与 `extractNaturalTime()` 两个函数，UI 和数据结构都不用动。注意 `onSmartInput()` 目前是同步实现，接入异步 API 时需要把它改成 `async` 并 `await` 结果；预览卡片依赖的数据结构保持为 `{ text, group, icon, priority, deadline }` 即可。

## 数据模型与本地存储

任务对象字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 时间戳 + 随机串 |
| `text` | string | 任务内容 |
| `group` / `icon` | string | 所属分组名 / 分组图标 |
| `done` | boolean | 是否完成 |
| `doneAt` | string \| null | 完成时间（ISO），用于「本周完成」统计 |
| `priority` | `high` \| `medium` \| `low` | 优先级 |
| `deadline` | string | 截止日期 `YYYY-MM-DD` |
| `createdAt` | string | 创建时间（ISO） |
| `subtasks` | `{ text, done }[]` | 子任务列表 |
| `repeat` | `weekly` \| null | 周期重复标记 |
| `expanded` | boolean | 子任务是否展开（UI 状态） |
| `tags` | string[] | 预留字段，当前 UI 未使用 |

`localStorage` 键：

| 键 | 内容 |
|----|------|
| `smartTodo.v2` | 任务数组 |
| `smartTodo.settings` | 设置：`theme` 主题、`notify` 是否开启到期通知、`notifyDate` 最近一次通知日期 |
| `smartTodo.templates` | 自定义模板；为空时回退到内置 6 个默认模板 |

导出文件结构：`{ version, exportedAt, todos, templates }`。

## 兼容性与已知限制

- **运行环境**：现代版 Chrome / Edge / Firefox / Safari。不使用 ES Module、`fetch` 或任何外部资源，因此 `file://` 直接打开即可运行；若浏览器限制本地存储，可用任意静态服务器打开（如 `python -m http.server`）。
- **数据归属**：数据只保存在你自己的浏览器（`localStorage`）中，换设备 / 换浏览器需通过导出的 JSON 迁移。
- **功能边界**：
  - 导入仍是**整体覆盖**：会替换当前全部任务（模板同理），覆盖前建议先导出一份备份
  - 到期通知需要安全上下文（`https` 或 `localhost`）：以 `file://` 直接打开时浏览器通常拒绝授权，点 `🔔` 会提示失败
  - 通知是「每个自然日最多一次」的逾期汇总提醒，不是分钟级闹钟；页面需保持打开（有每分钟定时检查，但没有 Service Worker / 后台推送）
  - 时间识别粒度较粗：「周末」「下个月」等词暂未换算为具体日期；命中一个时间词会作用于该次拆解的全部任务
  - 筛选与搜索状态不持久化，刷新后回到「全部」
  - 拖拽排序基于 HTML5 Drag & Drop，触屏设备体验有限（样式仅有 480px 一个断点）
