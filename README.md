# AI 生活清单 · 待办小助手

一个纯前端、无需后端的「带 AI 智能拆解感的待办清单」。输入一句话，本地规则引擎把它拆成结构化的分组任务。

## 功能

- **智能输入**：输入「下周去上海出差三天」，自动拆解成「✈️ 出差准备」分组 + 子任务
- **预览确认**：AI 拆解结果先以卡片预览，可勾选/修改，确认后才写入
- **分组视图**：任务按场景分组（出差/采购/学习/工作/生活/健康…），组头带微型进度条
- **持久化**：数据存 localStorage，刷新不丢
- **示例数据**：首次打开自动注入 8 条示例任务，方便直接体验各操作
- 支持：勾选完成 / 删除 / 筛选（全部/未完成/已完成）/ 清除已完成

## 技术栈

纯前端三件套，无构建、无依赖，双击 `index.html` 即可运行：
- `index.html` — 页面结构
- `style.css` — 样式
- `script.js` — 逻辑（含本地规则解析引擎）

## 用法

1. 双击 `index.html` 在浏览器打开，或用 VSCode Live Server。
2. 输入想法：
   - `下周去上海出差三天` → 出差分组
   - `周末去超市买点菜` → 采购分组
   - `这周把交易笔记复习完` → 学习分组
3. 在预览卡片里勾选/取消，点「确认添加」入列。
4. 点圆圈勾选完成，进度条实时更新。

## 本地规则解析（伪 AI）

`script.js` 中的 `RULES` 数组按关键词匹配分组并给出建议子任务；未来接真实 AI 时，只需替换 `parseInput()` 即可，UI 无需改动。
